✅ 🟢 Easy Coding Questions (Often Asked)

These are typical easy level problems — usually expected as first coding question:

Array Minimum / Maximum

Find the smallest number in an array

Find the largest number in an array

Reverse an Array

Given an array, reverse it.

Sum of Array Elements

Compute the total sum.

Count Frequency in Array

Count how many times each element appears.

Basic String Manipulation

E.g., replace vowels with a symbol or uppercase all characters.

Missing Number in Sequence

Given numbers from 1 to n with one missing, find it.

Check Prime / Leap Year

Check if a number is prime or if a year is leap year.

Simple Base Conversion

Convert a base-17 number to decimal.

👉 These focus on arrays, loops, simple logic — great for building confidence.

✅ 🟡 Medium / Hard Coding Questions

These have also appeared in recent years and are often the second question:

Subarrays With Given Sum
Count subarrays whose sum equals a target value.
Example: Input: [3,4,-7,1,3,3,1,4], sum = 7, output = 4

Count Subsets With Given Sum
Given an array and target sum, count how many subsets form this sum (DP).

Minimum Swaps to Group Ones
Count minimum swaps to group all 1s together in a binary array.

Make Array Beautiful
Rearrange array so adjacent elements alternate in sign using minimal operations.

Balanced Brackets with Wildcards
Determine if '?' can be replaced to make a valid bracket sequence.
